1. INTRODUCCIÓN Y ALCANCE

El presente documento detalla la estructura relacional, diccionario de datos, restricciones de integridad y scripts de operación de la base de datos para el sistema ERP Agro Peruvian Foods S.A.C.

El modelo soporta los cinco procesos troncales de la empresa agroindustrial:

  1. Catálogo e Inventario: Control de líneas de productos y stock consolidado.
  2. Compras y Proveedores: Abastecimiento de insumos agrícolas y empaques con RUC y control de saldos.
  3. Caja Chica y Arqueos: Apertura de turno, control de ingresos/egresos y cuadre de diferencias.
  4. Producción y Lotes (FEFO): Elaboración, mermas y despacho prioritario por caducidad (First Expired, First Out).
  5. Ventas y Despacho: Emisión de tickets y deducción automatizada del lote que expira primero.

2. MODELO ENTIDAD - RELACIÓN (RELACIONES PRINCIPALES)

  • CATEGORIAS (1:N) PRODUCTOS
  • PRODUCTOS (1:N) LOTES_PRODUCTO (control de caducidad)
  • PRODUCTOS (1:N) ORDENES_PRODUCCION (fabricación)
  • ORDENES_PRODUCCION (1:N) DETALLES_CONSUMO_INSUMO
  • PROVEEDORES (1:N) COMPRAS
  • COMPRAS (1:N) DETALLE_COMPRAS (ON DELETE CASCADE)
  • SESIONES_CAJA (1:N) MOVIMIENTOS_CAJA
  • VENTAS (1:N) DETALLE_VENTAS (ON DELETE CASCADE)
  • PRODUCTOS (1:N) DETALLE_VENTAS
  • LOTES_PRODUCTO (1:N) DETALLE_VENTAS (asignación FEFO)

4. CONSULTAS ANALÍTICAS PRINCIPALES

4.1. Despacho FEFO (Lotes prioritarios de salida)

SELECT 
    p.ID AS COD_PROD,
    p.NOMBRE AS PRODUCTO,
    l.CODIGO_LOTE,
    l.STOCK_DISPONIBLE,
    l.FECHA_VENCIMIENTO,
    TRUNC(l.FECHA_VENCIMIENTO - SYSDATE) AS DIAS_HASTA_VENCIMIENTO
FROM PRODUCTOS p
JOIN LOTES_PRODUCTO l ON p.ID = l.ID_PRODUCTO
WHERE l.STOCK_DISPONIBLE > 0
ORDER BY p.ID, l.FECHA_VENCIMIENTO ASC;

4.2. Arqueo y Control de Descuadre de Caja

SELECT 
    ID,
    CAJERO_NOMBRE,
    FECHA_APERTURA,
    MONTO_APERTURA,
    SALDO_TEORICO,
    SALDO_REAL,
    DIFERENCIA,
    CASE 
        WHEN DIFERENCIA = 0 THEN 'CUADRE EXACTO'
        WHEN DIFERENCIA > 0 THEN 'SOBRANTE'
        WHEN DIFERENCIA < 0 THEN 'FALTANTE'
        ELSE 'EN CURSO'
    END AS EVALUACION_ARQUEO
FROM SESIONES_CAJA
ORDER BY ID DESC;
