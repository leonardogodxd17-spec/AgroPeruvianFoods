1. Flujo de Secuencia Transaccional (Exitoso vs Rollback)
sequenceDiagram
    autonumber
    actor Vendedor as 👤 Vendedor POS
    participant SPA as 💻 Frontend (Angular 19)
    participant Backend as ⚙️ Spring Boot (Resource Server)
    participant Oracle as 🗄️ Oracle Database (BOM_VENTAS)
    participant Audit as 📋 Unified Auditing & EM Express

    Vendedor->>SPA: 1. Ingresa DNI y agrega productos al FormArray
    SPA->>Backend: 2. POST /api/v1/ventas (Payload Cabecera-Detalle + Bearer Token)
    
    Note over Backend,Oracle: Inicio de Transacción JDBC (@Transactional)
    Backend->>Oracle: 3. INSERT INTO VENTAS (Cabecera: cliente, total, vendedor_id)
    Backend->>Oracle: 4. INSERT INTO DETALLE_VENTAS (Detalle: producto, lote, cantidad)
    
    critical Verificación y Descuento en Base de Datos
        Oracle->>Oracle: 5. Dispara Trigger: TRG_DESCONTAR_STOCK_LOTE_VENTA
        alt Stock Disponible >= Cantidad
            Oracle->>Oracle: 6. UPDATE LOTES_PRODUCTO (Descuenta stock)
            Oracle->>Oracle: 7. COMMIT de la transacción
            Oracle-->>Audit: 8. Registra evento DML en UNIFIED_AUDIT_TRAIL
            Oracle-->>Backend: 9. Retorna ID y número de ticket generado
            Backend-->>SPA: 10. HTTP 201 Created (VentaResponse + Ticket 80mm)
            SPA-->>Vendedor: 11. Abre modal con Ticket Térmico listo para imprimir
        else Stock Insuficiente (Intento de sobreventa)
            Oracle->>Oracle: 6b. RAISE_APPLICATION_ERROR (-20001, 'Stock insuficiente')
            Oracle->>Oracle: 7b. ROLLBACK automático de toda la venta
            Oracle-->>Backend: 8b. Lanza DataIntegrityViolationException
            Backend-->>SPA: 9b. HTTP 400 Bad Request con mensaje de negocio
            SPA-->>Vendedor: 10b. Notificación de error en rojo (Sin afectación en BD)
        end
    end
